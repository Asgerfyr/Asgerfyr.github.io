Project Overview

Project Description

MilWeb er et webbaseret informationssystem designet til militær brug. Projektet er udarbejdet som et afsluttende eksamensprojekt i 3.g informatik og kombinerer teknisk udvikling med praktisk anvendelse i en realistisk kontekst. Formålet er at give generaler et overblik over troppebevægelser og soldaternes status via en brugervenlig platform.

Objectives

  • Udvikle sikkert login med rollebaseret adgang
  • Visualisere troppepositioner i realtid med Leaflet.js
  • Beskytte data med AES- og SHA256-kryptering
  • Strukturere databasen med klare relationer
  • Skabe en enkel og brugervenlig grænseflade

Key Features

Rollebaseret login og sikkerhed

Brugerne logger ind via en loginside, og deres adgang bestemmes af brugerrollen (soldat eller general).

Interaktivt kort (Leaflet.js)

Generalens interface viser et interaktivt kort, hvor troppernes positioner vises som farvede markører i realtid.

Sikkerhed og kryptering

Adgangskoder hashes med SHA256, og data i databasen krypteres med AES. HTTPS sikrer kommunikationen.

Realtidskommunikation

Systemet bruger fetch API'er til at sende og hente data mellem frontend og backend dynamisk.

Session og adgangskontrol

En middleware-komponent på serversiden sikrer, at kun brugere med rette adgangsrettigheder kan tilgå bestemte sider.

System Architecture Documentation

Frontend

Udviklet i HTML, CSS og JavaScript. Kortet er lavet med Leaflet.js, og designet bygger på gestaltlovene for at sikre brugervenlighed. Soldatsiden er optimeret til mobilbrug, mens generalsiden er lavet til desktopbrug.

Backend

Udviklet i Node.js med Express. Serveren bruger moduler og routers til at organisere forskellige endpoints, og anvender sessions for at huske login-status.

Database

MySQL anvendes til at gemme bruger- og missionsdata. Databasen indeholder relationelle tabeller for soldater, squads, missioner, advarsler og kommandoer. De fleste felter er krypteret med AES.

Database Model

Database-designet er lavet ud fra en E/R-model. Blandt tabellerne findes:

  • login: gemmer login-id, kodeord og salt
  • soldier: indeholder status, navn og rettigheder
  • squad: organiserer soldater i grupper med statusinformation
  • mission: gemmer missioner og deres tilhørende squads
  • warning og command: gemmer kritiske informationer

Positioner lagres i squad_location og knyttes til squads over tid. Dette muliggør historisk sporing.

UI Design Documentation

Brugerfladen i MilWeb er designet med fokus på enkelhed, funktionalitet og tydelig rolleopdeling. Der er udviklet to adskilte grænseflader - én til soldater og én til generaler.

Designprincipper

Brugergrænsefladen bygger på centrale gestaltlove for at sikre overskuelighed og brugervenlighed:

  • Figur/baggrund: Vigtige elementer skiller sig tydeligt ud fra baggrunden.
  • Nærhed: Relaterede elementer er placeret tæt sammen.
  • Lighed: Elementer med samme funktion har ens udseende.
  • Lukkethed: Formularer og funktioner er visuelt grupperet.
  • Responsivitet: Layout tilpasser sig brugerens enhed.

Generalens interface

Generalsiden er designet til større skærme og har et informationsrigt layout.

  • Kort (Leaflet.js): Viser squads som farvede cirkler med popups.
  • Tabelvisning: Viser squads med status, position og ID.
  • Navigation: En topbar med links til kort, missioner og advarsler.
  • Filtrering: Brugeren kan skjule visse typer data.

Soldatens interface

Soldatsiden er enkel og mobiloptimeret.

  • Inputfelter: ID, latitude, longitude og evt. status.
  • Send-knap: Afsender data til databasen via POST-request.
  • Minimal navigation: Kun én funktion pr. side.
  • Visuel enkelhed: Ingen overflødig grafik eller menuer.

Code Documentation

Koden er opdelt i moduler for at sikre overblik, genbrug og skalerbarhed. Backend er opbygget med Express.js og anvender både routers, middleware og controller-funktioner.

Modulstruktur

  • Routers: Hver funktion har sin egen routerfil, som modtager GET og POST-requests.
  • Middleware: En central komponent der håndterer autentifikation og rettighedstjek.
  • Controllers: Funktioner som tilgår databasen og håndterer forretningslogik.
  • Database-connector: Et modul, der laver forbindelse til MySQL-databasen.

Rettighedskontrol med middleware

Middleware-funktionen sikrer, at brugeren er logget ind og har de nødvendige rettigheder til at tilgå en rute.

app.use((req, res, next) => {
  if (!req.session.user) return res.status(403).send("Ikke logget ind");
  const roles = sitePermission(req.url);
  if (!roles.includes(req.session.user.role)) return res.status(403).send("Ingen adgang");
  next();
});

Eksempel: GET-request

fetch("/general/get_data")
  .then(res => res.json())
  .then(data => console.log(data));
router.get("/get_data", async (req, res) => {
  const [rows] = await db.query("SELECT * FROM squads");
  res.json(rows);
});

Eksempel: POST-request

fetch("/mission/send", {
  method: "POST",
  headers: {"Content-Type": "application/json"},
  body: JSON.stringify({ name: "Alpha", info: "Angreb øst" })
});
router.post("/send", async (req, res) => {
  const { name, info } = req.body;
  await db.query("INSERT INTO mission (name, description) VALUES (?, ?)", [name, info]);
  res.sendStatus(200);
});

Testing-Evaluation Documentation

Systemet blev testet løbende gennem udviklingsfasen og afslutningsvis evalueret gennem brugertests med fiktive scenarier for soldat og general.

Testresultater

FunktionResultatKommentar
Login (begge roller)✔️Let at forstå, fungerede stabilt
Position-afsendelse (soldat)✔️Hurtigt og simpelt
Kortvisning (general)⚠️Let at bruge, men overlappende markører skabte forvirring
Mission-afsendelse⚠️Funktionel, men krævede meget manuel indtastning
Navigation mellem sider⚠️Forvirrende at finde samme squad på tværs af sider
Responsivitet✔️Soldatsiden fungerede godt på mobil, generalsiden på desktop

Identificerede forbedringspunkter

  • Markørstyring på kort: Bedre håndtering og filtrering af overlappende positioner.
  • Brugerflow: Funktion til at følge en specifik squad på tværs af sider.
  • Forminput: Drop-downs eller preutfyldte felter kunne erstatte manuel indtastning.
  • Mission-overblik for soldat: Mangler mulighed for at se tildelte missioner.

Project Conclusion

Results

MilWeb fungerer som et rollebaseret, sikkert og brugervenligt system til militær koordinering. Systemet opfylder de vigtigste krav, herunder sikker login, visualisering af troppebevægelser og datakryptering.

Lessons Learned

Vi lærte, at små sikkerhedshuller som URL-manipulation og manglende brugeroverblik kan give utilsigtet adgang og dårlig brugeroplevelse. Fremover vil vi prioritere grundigere test af adgangskontrol og bedre brugerflow.

Future Improvements

  • Forbedret markørstyring og filtrering på kortet
  • Mulighed for soldater at se egne missioner og opgaver
  • Bedre brugerflow mellem generalens sider
  • Bedre validering af URL'er mod sårbarheder
  • Udbygning af database med historik og flere relationer
